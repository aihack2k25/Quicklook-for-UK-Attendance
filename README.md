# Quicklook - Agent for UK Schools Attendance
## Overview
Quicklook is your expert virtual assistant for all UK schools attendance guidelines, policies, and best practices, grounded in the Department for Education (DfE) framework. The agent delivers authoritative answers for schools, parents, and local authorities, offering guidance on attendance requirements, statutory duties, absence reporting, intervention strategies, and regulatory compliance. Its aim is to boost attendance rates by supporting evidence-based decision making.It also keeps track of the national data for the Absence rates for different contexts.

## Features
**Accurate, real-time answers:** Offers up-to-date information on attendance requirements, legal responsibilities, and statutory guidance.
**Practical strategies:** Suggests intervention approaches for persistent absence and practical ways to improve attendance.
**Comprehensive support:** Guides on attendance management systems, responsibilities for schools, parents, and local authorities.
**Context-aware suggestions:** Responds with relevant topics and information, including legal thresholds, codes, reporting, supports, and rewards.

## Data Sources
- Latest government frameworks (e.g. Working Together to Improve School Attendance).
- Official documents and statutory guidance from gov.uk.
- Publications and datasets from DfE and related agencies.
- Historic and current absence rates at the national level.

## Backend Flow
**User Query:** A user asks a question about school attendance or related policies.<br>
**Intent Recognition:** Copilot identifies and extracts the inquiry theme (e.g., legal thresholds, reporting, codes).<br>
**Guidance/Data Retrieval:** The agent finds relevant policy information or statistics from DfE guidance or datasets.<br>
**Response Generation:** The AI delivers a fact-based answer, offering further suggestions or clarifications as needed.<br>
**Continuous Support:** The agent suggests related topics and guides users through follow-up queries if desired.<br>

## Target Audience
- School administrators, leaders, and staff.
- Policy makers and local authorities.
- Parents and carers.
- Education researchers.
- Students (for awareness purposes).

## Technologies Used
Microsoft Copilot Studio (primary platform for agent design and deployment).
Natural Language Processing (for understanding and responding to queries).
DfE Data Integration (manual or API-based data feeds depending on implementation).
Chat interface via Microsoft teams (for test and user access).

## Getting Started
- Tool: An account or environment for Microsoft Copilot Studio.
- Deployment: Use a web agent or, if configured, integrate with Microsoft Teams. A chat box with natural language is used for user interaction.
- Customisation: As new DfE guidelines are released, update agent knowledge accordingly. As needed, incorporate more datasets or add more topics.
